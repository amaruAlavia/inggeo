# INGGEO MYM SpA — Landing Page Corporativa

Landing page de alto impacto para **INGGEO MYM SpA**, empresa chilena especialista en termofusión, instalación de geomembranas HDPE, obras hidráulicas, obras civiles y movimiento de tierras en el norte de Chile.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico**: Estructura limpia y accesible.
- **Tailwind CSS**: Estilos modernos y responsivos con paleta corporativa (`#7E22CE` / `#0F172A`).
- **Lucide Icons**: Iconografía técnica vectorial.
- **JavaScript Moderno**: Interactividad para menú móvil y cotizador con enlace automático a WhatsApp.
